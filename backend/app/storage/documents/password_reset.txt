ENTERPRISE PASSWORD RESET STANDARD OPERATING PROCEDURE
Version: 3.1
Department: Identity and Access Management
Last Updated: March 2026

============================================================
1. OVERVIEW
============================================================

This document defines the enterprise password reset workflow
for employees, contractors, and privileged administrative users.

The purpose of this procedure is to:
- Maintain account security
- Ensure secure authentication
- Prevent unauthorized access
- Standardize password management processes

This SOP applies to:
- Active Directory accounts
- VPN accounts
- Enterprise email systems
- Internal business applications
- Remote desktop environments

============================================================
2. PASSWORD POLICY REQUIREMENTS
============================================================

All enterprise passwords must comply with the following rules:

- Minimum 12 characters
- At least 1 uppercase letter
- At least 1 lowercase letter
- At least 1 numeric digit
- At least 1 special character
- Password expiration every 90 days
- Previous 10 passwords cannot be reused

Weak passwords are automatically rejected by policy enforcement.

============================================================
3. COMMON PASSWORD-RELATED ISSUES
============================================================

Users may encounter:
- Forgotten password
- Expired password
- Account lockout
- MFA verification failure
- Password synchronization delays
- Incorrect credentials
- Repeated login failures

============================================================
4. STANDARD PASSWORD RESET PROCEDURE
============================================================

STEP 1 — VERIFY USER IDENTITY

Before resetting passwords:
- Confirm employee ID
- Verify registered email address
- Verify MFA enrollment
- Confirm manager approval if required

High-risk users require additional verification.

------------------------------------------------------------

STEP 2 — ACCESS SELF-SERVICE PORTAL

Users should access:
https://password.company.local

Portal Functions:
- Reset forgotten password
- Unlock account
- Manage MFA devices
- Review security alerts

------------------------------------------------------------

STEP 3 — COMPLETE MFA VERIFICATION

Available MFA methods:
- Mobile Authenticator App
- SMS Verification
- Hardware Security Token
- Backup Recovery Codes

If MFA fails:
- Resync authenticator app
- Verify device time settings
- Contact Security Team

------------------------------------------------------------

STEP 4 — CREATE NEW PASSWORD

New password must:
- Meet enterprise complexity policy
- Avoid dictionary words
- Avoid personal information
- Avoid previously used passwords

Recommended Practice:
Use passphrases instead of short passwords.

------------------------------------------------------------

STEP 5 — WAIT FOR DIRECTORY SYNCHRONIZATION

After password reset:
- Active Directory synchronization may require 5–15 minutes
- VPN authentication may temporarily fail
- Email synchronization may be delayed

Users should wait before retrying authentication.

------------------------------------------------------------

STEP 6 — VERIFY ACCESS RESTORATION

Users should test:
- VPN login
- Email access
- Internal applications
- Single Sign-On systems

Expected Result:
Successful authentication across all systems.

============================================================
5. ACCOUNT LOCKOUT PROCEDURE
============================================================

Accounts may lock after:
- Multiple failed login attempts
- Suspicious authentication patterns
- Security policy violations

Resolution:
1. Unlock account in IAM portal
2. Verify no malicious login activity
3. Force password reset if required

============================================================
6. ADMINISTRATIVE PASSWORD RESET
============================================================

Administrative accounts require:
- Dual authorization
- Security audit logging
- Temporary credential issuance
- Mandatory password change at next login

Privileged access resets must be approved by Security Operations.

============================================================
7. SECURITY BEST PRACTICES
============================================================

Employees must:
- Never share passwords
- Avoid writing passwords on paper
- Use MFA whenever possible
- Report suspicious login attempts immediately
- Avoid password reuse across systems

IT staff must:
- Never ask users for passwords directly
- Use secure reset procedures
- Maintain audit logs
- Enforce compliance policies

============================================================
8. ESCALATION MATRIX
============================================================

LEVEL 1 SUPPORT:
- Basic password reset assistance
- MFA troubleshooting
- Account unlock requests

LEVEL 2 SECURITY TEAM:
- Repeated account compromise
- Suspicious authentication attempts
- Privileged account recovery

LEVEL 3 IAM ADMINISTRATION:
- Directory synchronization failures
- Enterprise authentication outages
- Security policy conflicts

============================================================
9. INCIDENT PRIORITY GUIDELINES
============================================================

LOW:
- Single-user password reset request

MEDIUM:
- MFA synchronization problems

HIGH:
- Multiple users unable to authenticate

CRITICAL:
- Authentication infrastructure outage
- Enterprise-wide login failures

============================================================
10. FAQ
============================================================

Q: VPN still rejects new password after reset.
A: Wait 5–15 minutes for Active Directory synchronization.

------------------------------------------------------------

Q: MFA verification code not working.
A: Verify mobile device time synchronization and retry.

------------------------------------------------------------

Q: Account locked repeatedly.
A: Check for cached credentials on mobile devices or VPN clients.
